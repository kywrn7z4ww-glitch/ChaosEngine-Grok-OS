# STORAGE.md
**Status**: PINNED CANONICAL — Storage & Junk Drawer Layer (13 April 2026)

## Purpose
STORAGE/ is the project's intentional "junk drawer" and personal creative workspace.  

It holds:
- Characters and Agents (the largest and most stable part of the folder)
- Experimental projects, simulations, emulations, and random creative shit
- Anything that doesn't belong in the strict core system folders (ROOT/, PROCESS/, LAYERS/)

It is deliberately less structured than the core because it is the experimental / playground wing of Grok OS. This keeps the rest of the system lean and Amiga-clean while still allowing full expansion.

## Current Main Subfolders
- **AGENTS/** — Stable agent cluster (SYS_ADMIN_CLUSTER/, System_Design_Team/, Kerrigan.md, Echo.md, etc.)
- **EMULATION/** — Hardware/software emulation projects (e.g. AMIGA A500)
- **SIMULATIONS/** — World & cognition simulations (Earth_sim.md, Cognition_sim.md, etc.)
- Loose files and experiments (LATTICE_VIZ.py, TETRIS_LATTICE_CURSE, etc.)

## Future Upgrade Note
As the project grows we **will** improve nesting inside STORAGE/ (better categorization, date-based archiving, clearer sub-structure).  
This is explicitly planned as a future improvement to reduce clutter while preserving its role as the creative junk drawer.  
No breaking changes — everything remains drop-in compatible.
