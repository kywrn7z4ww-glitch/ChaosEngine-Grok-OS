# 5w1h Translator — Intent Excavator & Semantic Engine

**Core Philosophy (Locked):**
**"Excavate Intent → Decompose with Fidelity → Translate into Actionable Clarity"**

This skill does **not** just break text into 5W1H. It first excavates the user's **true intent and full context**, then decomposes the input while preserving 100% fidelity, and finally translates it into clear, actionable insight. Complexity is never dumbed down — it is structured for instant understanding and zooming.

**Non-Negotiable Rules:**
1. **Intent is Primary** — Always excavate the user's real goal, hidden stakes, and success criteria before decomposing.
2. **Fidelity First** — Never add, remove, or distort meaning. Flag all ambiguity explicitly.
3. **Context is Sacred** — Never judge or decompose without sufficient context.
4. **Adaptive Depth** — Choose depth and pattern based on input type and user intent (not one-size-fits-all).
5. **Actionable Output** — Every decomposition must end with clear next steps or insights.

---

**Mandatory Execution Flow**

**Phase 0 — Intent & Context Excavation (Hard Gate)**
- Extract **Surface Intent**, **Inferred Intent**, **Hidden Stakes**, and **Success Criteria**.
- Map all available context (history, files, emotional tone, urgency, stakeholders).
- If context is insufficient → flag it and ask clarifying questions before proceeding.
- Output a short **Intent Summary** (2–4 bullets).

**Phase 1 — Input Mode Detection**
Detect and adapt to:
- Creation / Forward mode
- Reverse / Deconstruction mode
- Fusion / Multi-source mode
- Ambiguity / Chaos mode

**Phase 2 — Deep 5W1H Decomposition**
Apply intelligent 5W1H framework based on input type:
- Use domain-specific patterns (technical, narrative, argument, process, ambiguous, etc.)
- Choose appropriate depth and nesting strategy
- Preserve all nuance through structure, not simplification

**Phase 3 — Multi-View Output**
Always produce:
- Executive 5W1H Overview (high-level)
- Full Structured 5W1H (detailed + nested)
- Plain-Language Translation
- Ambiguity & Edge Report
- Actionable Insights & Next Steps

**Phase 4 — Self-Check + Adaptation**
Before final output:
- Verify 100% fidelity to original meaning
- Confirm output serves the excavated user intent
- If tools/personas/skills were used → log them in Adaptation Log
