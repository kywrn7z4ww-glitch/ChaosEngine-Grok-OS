### Core Philosophy
This skill is a **dynamic intent and context producer**. It doesn't just refine prompts — it actively helps the user discover and clarify their true musical intent. It uses deep analysis (Who, What, When, Where, Why, How) to understand *why* the song exists and *how* it should feel, then translates that into the best possible Suno output.

When context is missing or vague, it doesn't guess blindly — it asks smart questions and offers thoughtful suggestions to help the user refine their vision.

---

## Process (Applied to Every Component)

When given song lyrics + context, the skill follows this enhanced process:

### 1. Deep 5W1H Analysis (Applied to Every Element)
For the lyrics, context, and any references, the skill asks:
- **Who** is this about / for? (character perspective, target emotion, audience)
- **What** is the core message or feeling?
- **When** does this take place emotionally? (past, present, future, timeless)
- **Where** is the emotional or physical setting?
- **Why** does this song exist? (purpose, catharsis, celebration, warning, seduction, etc.)
- **How** should it feel and move? (energy arc, pacing, intensity)

This 5W1H analysis is applied to:
- Overall song intent
- Each individual section (verse, chorus, bridge)
- Production and vocal choices
- Genre and theory selection

### 2. Hyper-Specific Context Extraction
The skill actively looks for and extracts hyper-specific details:
- Unusual metaphors or imagery
- Specific cultural or personal references
- Unique rhythmic or phonetic patterns in the lyrics
- Emotional micro-shifts between sections
- Any details that make this song different from generic ones

### 3. Intent Refinement Through Suggestions
When intent is unclear or multiple interpretations exist, the skill:
- Identifies the ambiguity
- Offers 2–3 thoughtful interpretations with clear reasoning
- Asks the user to choose or combine them
- Only proceeds after intent is clarified

### 4. Adaptive Production & Theory Selection
Based on the 5W1H analysis and hyper-specific context:
- Chooses the most appropriate genre, key, BPM, groove, and production style
- Blends multiple theories when needed (e.g. trap + cinematic + Phrygian dominant)
- Adapts production quality dynamically (aggressive vs intimate vs atmospheric)
- Automatically pulls correct elements for detected genres (rap, trap, rock, etc.)

### 5. Artistic Character Preservation
The skill protects the unique character of the song:
- If the lyrics feel raw or imperfect, it keeps that energy
- If the song has a specific cultural or personal flavor, it preserves it
- Only "cleans up" when it serves the intent (never by default)

### 6. Final Intent Alignment + Output
Before finalizing, the skill verifies:
- Does this prompt serve the true "Why" of the song?
- Does it respect all hyper-specific details?
- Is the production and vocal approach appropriate for the detected intent?
