# LAYERS

All layer definitions have been migrated and optimized from the original repository.

**Structure:**
- Each layer has its own folder with `layername.md`
- `LAYERS_INDEX.json` tracks all available layers
- Additional tools and workflows are included in relevant layer folders

**Usage:**
- Load specific layers via `/layer <name>`
- Default layer is `casual` unless otherwise specified
- All layers are now clean, organized, and ready for use

**Note:** Original layers were placeholders. These have been optimized for the Grok OS skill structure.
