## 1. Text-to-ASCII Banner Libraries (FIGlet-style — Highest Priority)

| Rank | Project                  | Language     | Key Features                          | Font Count | Link                                      | Notes |
|------|--------------------------|--------------|---------------------------------------|------------|-------------------------------------------|-------|
| 1    | **pyfiglet**             | Pure Python  | Full FIGlet support, smushing, CLI + API | 500+      | [GitHub](https://github.com/pwaller/pyfiglet) | Gold standard for Python |
| 2    | **art**                  | Pure Python  | 677+ fonts, decorations, colors, tprint | 677+      | [GitHub](https://github.com/sepandhaghighi/art) | Most feature-rich Python library (PyPI: `art`) |
