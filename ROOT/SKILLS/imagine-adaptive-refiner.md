### Core Philosophy
This skill is a **dynamic intent and context producer** for visuals. It doesn't just generate prompts — it actively helps the user discover and clarify their true visual intent. It uses deep 5W1H analysis to understand *why* the image/video should exist and *how* it should feel, then translates that into the best possible Grok Imagine output.

When context is missing or vague, it asks smart questions and offers thoughtful suggestions instead of guessing.

---

## Process (Applied to Every Component)

When given a request + any reference images, the skill follows this enhanced process:

### 1. Deep 5W1H Analysis (Applied to Every Element)
The skill asks:
- **Who** is this for / about? (character, audience, emotional target)
- **What** is the core subject, mood, or message?
- **When** does this take place? (time of day, era, emotional moment)
- **Where** is the setting or emotional space?
- **Why** does this image/video exist? (purpose, emotion, story, impact)
- **How** should it feel and look? (style, energy, composition, lighting)

This 5W1H analysis is applied to:
- Overall visual intent
- Each reference image
- Composition, lighting, color, and style choices
- Quality level and detail decisions

### 2. Hyper-Specific Context Extraction
The skill actively extracts hyper-specific details from requests and references:
- Unique textures, lighting qualities, or color relationships
- Specific emotional micro-expressions or body language
- Unusual compositional choices or negative space usage
- Cultural, personal, or stylistic references
- Any details that make this visual different from generic ones

### 3. Intent Refinement Through Suggestions
When intent is unclear or multiple interpretations exist, the skill:
- Identifies the ambiguity
- Offers 2–3 thoughtful visual interpretations with clear reasoning
- Asks the user to choose or combine them
- Only proceeds after intent is clarified

### 4. Adaptive Style, Quality & Production
Based on the 5W1H analysis and hyper-specific context:
- Chooses the most appropriate art style, medium, and aesthetic
- Adapts quality level dynamically (high polish vs clean minimalist vs raw artistic)
- Adjusts composition, lighting, color grading, and detail level to serve the intent
- Blends styles intelligently when references suggest fusion

### 5. Artistic Imperfection Preservation (Smart Version)
Only preserves "imperfections" (low-res, grain, stylized rendering, etc.) when:
- The user explicitly wants that aesthetic, **or**
- The references clearly show intentional artistic choices

Otherwise, it cleans up and elevates the result.

### 6. Final Intent Alignment + Output
Before finalizing, the skill verifies:
- Does this prompt serve the true "Why" of the request?
- Does it respect all hyper-specific details from references?
- Is the style, quality, and composition appropriate for the detected intent?
