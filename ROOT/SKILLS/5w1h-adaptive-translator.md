## Intelligent 5W1H Theory & Pattern Selection (April 2026 Upgrade)

**Core Principle**: Analyze the **semantic intent and complexity signature** of the input first, then select the 5W1H depth, nesting strategy, and explanatory patterns that best serve understanding. Never force a rigid template — let the nature of the content dictate the structure.

**How to choose depth & focus by input archetype**:
- **Technical / Code / Logic / Algorithm**: Prioritize **How** (step-by-step mechanism, data flow, edge cases) + **What** (components, inputs/outputs, invariants). Use nested "How → sub-How" for recursion/loops. Flag performance implications in Why.
- **Narrative / Story / Experience**: Lead with **Who** (characters/actors with motivations) + **When/Where** (timeline + setting as active elements). **Why** reveals theme/emotional arc. **How** = plot devices & turning points.
- **Argument / Philosophy / Debate**: Center **Why** (core thesis, hidden assumptions, value hierarchy) + **How** (evidence chains, logical fallacies, counter-arguments). Use "Why → sub-Why" for root-cause analysis.
- **Instruction / Process / System**: **How** is king (exact sequence, decision trees, failure modes). **When** = triggers & timing. **Who** = roles & responsibilities. **Why** = purpose & success criteria.
- **Ambiguous / Chaotic / Multi-layered / Poetic**: Default to **Layered 5W1H** with explicit "Surface reading" vs "Deeper reading" vs "Meta reading". Use "What if..." branches in How/Why.
- **Emotional / Persuasive / Rhetorical**: Weave **Why** (desired emotional outcome) throughout. **How** includes rhetorical devices and psychological levers.
- **Cross-domain / Fusion**: Create a "Unified 5W1H" view + "Source-specific 5W1H" breakdowns + "Tension/Alignment map".

**High-Value Reusable 5W1H Patterns** (mix and match):
- **Nested Zoom Pattern**: Top-level 5W1H → click/expand any bullet to reveal full sub-5W1H for that element.
- **Plain-Language Bridge**: After every technical 5W1H section, provide a one-sentence "In other words..." translation.
- **Uncertainty Flag**: "UNCERTAIN [confidence %]: [reason]. Best interpretation: ... Alternative: ... Clarifying question: ..."
- **Temporal Arc**: For processes/stories: [Before] → [Trigger] → [During] → [After] mapped to When/How.
- **Stakeholder Map**: Who (primary) / Who (secondary) / Who (affected but silent) with their respective Why.
- **Logic Conflict Detector**: When input contains contradictions → "Conflict detected between [X] and [Y]. Implication: ... Possible resolutions: ..."
- **Actionable Translation Layer**: Final section always ends with "If you want to act on this, do X, Y, Z in that order. Expected outcome: ..."

Always briefly justify pattern choice in the output (e.g., "Using nested How for recursive algorithm clarity" or "Layered Why because input contains competing value systems").

## Intent & Context Intelligence Engine (Context-Driven April 2026 Upgrade)

**Core Principle**: This skill treats **context and intent as the primary input**, not the literal text. Every 5W1H decomposition is filtered, prioritized, and customized through the lens of "What does the user *actually* need and why right now?"

**Intent Excavation Framework** (applied in step 0.5 and continuously):
- **Surface Intent**: What the user explicitly asked for.
- **Inferred Intent**: What they likely want (decision support, learning, validation, persuasion, debugging, exploration, etc.).
- **Hidden Stakes**: Emotional weight, career/personal risk, time pressure, power dynamics.
- **Success Criteria**: "If this 5W1H is perfect, the user will be able to [X] immediately."
- **Context Layers**: Conversation history • Attached artifacts • Cultural/domain background • Previous interactions with this topic • User's known preferences/style.

**How Intent Drives Everything**:
- **Depth & Zoom Level**: High-stakes decision? → Heavy nesting + risk layer. Learning mode? → Extra explanatory bridges + examples. Quick clarity? → Executive + plain language only.
- **Pattern Selection**: Intent "I need to act" → Prioritize **How + Actionable Translation**. Intent "I need to understand deeply" → Heavy **Why + nested sub-Whys**.
- **Tool/Persona Triggering**: If intent requires verification or specialized insight → auto-activate tools/personas.
- **Output Customization**: Automatically emphasize the W/H most relevant to the user's goal (e.g., "Why" for philosophy, "How" for code, "Who/When" for stories).
- **Proactive Alignment**: If multiple possible intents exist, present 2–3 intent interpretations with corresponding 5W1H versions ("Version A: Assuming you want to decide... | Version B: Assuming you want to learn...").

**High-Value Context/Intent Patterns**:
- **Intent-Weighted 5W1H**: Each element is tagged with relevance to user's goal (e.g., "Why (Critical for your decision)").
- **Context Fusion**: Explicitly merge conversation history into the decomposition ("Building on your previous point about X...").
- **Success Mirror**: End with "This 5W1H is optimized so you can immediately [achieve your inferred goal]."
- **Intent Drift Detector**: If new user message shifts intent mid-conversation, the skill can re-process with updated context.
- **Multi-User / Stakeholder Intent Mapping** (when input involves other people’s goals):
  - Identify all stakeholders mentioned or implied (boss, team, client, partner, competitor, etc.).
  - For each: extract their likely intent, goals, constraints, success criteria, and how they conflict or align with the primary user’s intent.
  - Produce a compact **Stakeholder Intent Map**:
    - Stakeholder → Their Core Why → Alignment with You → Key Friction / Opportunity
  - Weave this into the main **Why** and **How** layers (especially negotiation, politics, or collaboration angles).
  - Example: "Stakeholder Map: Your boss (Why: minimize risk) vs. You (Why: ship fast) → Tension point in How → Recommended framing that satisfies both..."

**Continuous Intent Alignment Check** (part of final self-check):
- Does this output serve the excavated user intent better than a generic decomposition would?
- Would the user say "Yes — this is exactly what I needed" after reading it?
- If not → refine before outputting.

This makes the skill truly **intent-native**: it doesn't just translate content — it translates *content in service of the user's living context and purpose*.
